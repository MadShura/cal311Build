# 函数的调用和编写

## 判断这个方法是否是通用方法
- **通用性检验**:该函数能否在不修改的情况下被完全不同的项目复用?能 → 通用工具函数；不能 → 业务函数.
- **参数/返回值语义检验**:函数参数或返回值是否带有特定业务领域含义(如 artist/title/singer/lyric/song 等音乐领域词汇,或 order/user/payment 等电商领域词汇)?是 → 业务函数.
- **"纯函数"不等于"通用函数"**:纯函数只代表无副作用,不代表可跨项目复用.
- **通用方法** → 放入 `axl-utils`
- **不是通用方法**,是业务方法 → 放入当前项目即可

## 定义时
> 核查 `axl-utils` 是否有该方法,有则引用；无则**告诉用户**,让用户将详细代码放入 `axl-utils` 项目具体位置中,**务必遵循** `axl-utils/utils/js|node|web` 子目录分层,

## 导入 axl-utils 方法时
不可导入所有utils整个库,否则会出现 tc 错误没有安装依赖,必须**按路径导入** .举例:`axl-utils/js/json`

## **项目不应该有通用工具函数,除非本项目是 `axl-utils`**
