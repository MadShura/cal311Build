# 注释写作规范

## 核心规则
- **不得删除有效注释**；过期/失效注释必须删除。过期判断依据：注释描述的行为与当前代码不符、引用了已删除/重命名的符号、TODO 已完成；拿不准时不删，先问用户。
- 生成的方法需附 JSDoc 中文注释；简单 getter/setter、一目了然的一行函数可省略，注释写给「需要解释为什么」的地方。

## 结构分区(#region)

- **仅 ts/tsx/js/jsx 使用** `// #region 名称` / `// #endregion`；**vue / html 不写**.
- 其他语言按该语言注释符 + `region` 关键字(如 css 用 `/* #region */`),**必须以该语言合法注释符开头**,裸写 `#region` 视为非法.
- 按职责分区,一个文件 2~5 个区为宜.
- region 不属于注释内容；**空 region 务必删除**(预留结构需在 region 名注明 `预留`,否则视为空壳删除).

## 修改前置检查

- 修改前扫描目标文件全部注释中的禁令关键词:`严禁`、`禁止`、`不允许`、`勿`、`不要`、`不可`、`慎改`、`勿动`.
- 命中禁令且与任务冲突时:**暂停修改,向用户说明冲突点,由用户决定**；用户明确同意后才可改.
